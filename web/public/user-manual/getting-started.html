Introduction

OptionsLab is an open-source options research and backtesting stack you run yourself: FastAPI backend, SQLite or Postgres, and a Next.js dashboard. It combines:

  • Historical backtesting — run stock and options strategies against your own synced data.
  • Time-series forecasting (AI) — ARIMA and gradient-boosting models to predict short-term price direction.
  • Strategy engine — evaluate options payoffs using forecast distributions, with automated strategy discovery.
  • Volatility Dashboard — Historical Volatility, IV Rank, IV Percentile, and Expected Move to time strategy entry.
  • Risk tools — Kelly Criterion position sizing and break-even price analysis.
  • Research Assistant — GPT-4o-mini (or placeholder) with a built-in financial RAG knowledge base for plain-language explanations.
  • Macro data — FRED, BLS, and BEA economic indicators charted alongside your trading results.
  • E*TRADE integration — live and sandbox order placement (optional).
Who is this for? Operators and traders who will clone the repo, install dependencies, and keep the API and web processes running. End users only need the dashboard; this manual focuses on what you need to run it.

Quick start

You need Python 3.10+, Node.js 18+, and Git. Use two terminals: one for the API (port 8000), one for Next.js (port 3000).

Installation

Clone and set up Python virtualenv 
git clone https://github.com/your-org/OptionsLab
cd OptionsLab
python3 -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
Seed demo data (no API keys required) 
PYTHONPATH=. python scripts/seed_dummy_data.py

Creates a local SQLite database with AAPL and MSFT price history so every feature can be explored immediately.

Start the API server 
PYTHONPATH=. uvicorn api.main:app --reload --host 0.0.0.0 --port 8000
Start the frontend (new terminal tab) 
cd web && npm install && npm run dev
Open the app

Open http://localhost:3000 (or your machine’s LAN IP on port 3000). Go to /register, create an account, then use the dashboard.

LAN access Next dev binds to 0.0.0.0. From another device use http://<host-ip>:3000. The UI defaults the API to the same hostname on port 8000 unless NEXT_PUBLIC_API_URL is set in web/.env.local.
Environment Create a .env in the repo root for the API (see root README.md). Optional: web/.env.local with NEXT_PUBLIC_API_URL=http://localhost:8000 if the API is not on the same host as the page.

Registration & Login

OptionsLab uses JWT-based authentication. Every user has a private account; multiple users can share one server instance.

Create an account

Open /register on your web origin (e.g. http://localhost:3000/register). Enter your email and password (at least 8 characters). Passwords are hashed with bcrypt — never stored in plain text.

Sign in

Open /login. On success, a JWT is stored in localStorage and sent on API requests. Tokens expire after 24 hours; sign in again to renew.

Sign out

Click Sign out in the sidebar. This clears local storage; the token is not revoked server-side (stateless JWT).

Production note Set JWT_SECRET_KEY to a strong random value in your .env before deployment: python -c "import secrets; print(secrets.token_hex(32))"
