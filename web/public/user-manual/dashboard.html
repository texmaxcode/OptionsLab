Data & Symbols Page

Browse, sync, and inspect all market data stored in the local database.

Syncing data

Use the sidebar controls to pick a symbol, date range, and source, then click Sync now. Alternatively, use the CLI:

# Massive (historical OHLCV + options)
PYTHONPATH=. python scripts/sync_data.py --source massive \
  --symbol AAPL --from 2024-01-01 --to 2024-12-31

# E*TRADE (quotes + option chain snapshot)
PYTHONPATH=. python scripts/sync_data.py --source etrade \
  --symbol AAPL --options --max-contracts 50

Browsing data

Select a symbol from the dropdown to see:

  • Candlestick chart — OHLCV price history. Highlighted indices appear when a backtest is selected.
  • Paginated bars table — All underlying bars with open, high, low, close, volume.
  • Contracts list — All stored options contracts for the symbol (strike, expiry, type).
Price privacy When the controls panel is open, prices on the chart are dimmed for focus. Prices are visible when you collapse the controls panel.

Macro & Economics Page

Pull in economic indicators from FRED, BLS, and BEA to put your options strategies in macroeconomic context.

Loading data

Pick a source and series ID from the presets, choose a date range, and click Load live to fetch from the API (requires the relevant API key in Settings or .env). Click Save to DB to persist it for offline use.

Bulk import

Import all preset series at once via the CLI (requires the API server running):

PYTHONPATH=. python3 scripts/sync_economic.py \
  --all-presets --from 2015-01-01 --to 2024-12-31 --to-db

Research & AI Page

The core analytical engine of OptionsLab. Four interconnected cards work together in a natural trading workflow:

1 · Run Forecast

Fit a time-series model on historical bars and produce a short-term direction signal.

FieldDescription
SymbolMust be synced to the DB first.
From / ToTraining period. Pre-filled from Settings defaults.
ModelARIMA — autoregressive linear model, fast, good for trend. Gradient Boost — tree ensemble on lagged features, better for non-linear patterns.
HorizonDays ahead to forecast (1–30).

Result: Direction badge (up / down / flat) and the final forecast price value.

2 · Evaluate Strategy

Use the forecast as an input to compute the expected payoff of an options strategy.

Inputs (Row 1 — always visible):

  • Strategy type — straddle, bull call spread, bear put spread, iron condor, calendar spread (call or put).
  • Forecast mean — the expected underlying price at expiry. Auto-filled from "Run Forecast".
  • Forecast std — optional standard deviation; widens the probability distribution.
  • Premium paid ($) — optional; net debit (positive) or credit received (negative). Enables break-even price display.

Inputs (Row 2 — strategy-specific):

StrategyExtra fields shown
StraddleStrike
Bull call / Bear put spreadLong strike, Short strike
Iron condorPut long, Put short, Call short, Call long
Calendar spreadStrike, Net debit

Results:

  • A 2×2 metric grid: Expected Value, P(profit), Max Loss, Max Gain.
  • Break-even prices as amber badges (when Premium paid is provided).
  • Interactive payoff diagram.
  • Historical backtest comparison return (optional — enable "Include historical backtest").

3 · Full Analysis

Runs the complete pipeline in one click: Forecast → Strategy evaluation → AI explanation. Same inputs as the forecast card. The Research Assistant (with RAG context) generates a plain-language summary of what the data means and which strategies fit the current environment.

OpenAI API key Without a key the explanation is a well-structured placeholder. Set your key in Settings → AI & Research. The key is stored per-user and takes precedence over any OPENAI_API_KEY env var.

4 · Position Sizing

Compute the mathematically optimal trade size before entering. See Kelly Criterion for the underlying theory.

  • Enter your capital, historical win rate, average win/loss amounts, and max risk %.
  • Optionally enter max loss per contract to compute max contracts.
  • Results: Full Kelly %, Half Kelly % (recommended), Fixed Risk $, Max Contracts.

Volatility Dashboard

Choose when to enter a trade before choosing which trade. This page answers: are options cheap or expensive right now?

How to use it

Select a symbol and date range, click Analyze.

The date range controls how much history is used to calculate IV Rank and HV. A full year of data gives the most meaningful IV Rank reading.

Read the IV Rank gauge.

The progress bar fills left-to-right from 0 to 100. Green = low (options cheap), yellow = moderate, red = high (options expensive).

Read the Strategy Guidance card.

A colored dot and short paragraph summarize the recommended strategy class for the current vol environment.

Compare IV and HV-20 on the chart.

When the orange IV line is above the green HV-20 line, options are pricing in more movement than has been realized — a premium-selling environment.

Metrics at a glance

MetricWhat it tells youData needed
HV-10 / 20 / 30 / 60How much the stock has been moving historically (annualized).Underlying bars only
Current IVThe market's forward-looking volatility expectation.Options bars with IV
IV Rank (IVR)Where today's IV sits within the past year's range (0–100).Options bars with IV
IV Percentile (IVP)% of trading days where IV was lower than today.Options bars with IV
Expected Move (30d)±$ / ±% one-sigma range the market implies over 30 days.Options bars with IV
No IV data? The HV windows are computed from underlying bars alone. The IV Rank, IV Percentile, Expected Move, and chart require options contracts with implied volatility to be synced.

Backtests Page

Create, browse, and inspect historical strategy simulations powered by Backtrader.

Creating a backtest

Go to Backtests → New backtest.
Select a strategy, symbol, and date range.

Defaults are pre-filled from Settings. Starting cash defaults to $100,000.

Click Run.

The backend runs the Backtrader simulation and saves the equity curve and all trades.

Available strategies

StrategyTypeDescription
sma_crossoverStockLong when the 10-day SMA crosses above the 30-day SMA; flat otherwise.
sma_rsiStockSMA crossover filtered by RSI (only long when RSI < 70).
single_legOptionsBuy and hold one options contract to expiry.
covered_callOptionsLong underlying + short call. Income-generating, capped upside.
protective_putOptionsLong underlying + long put. Downside protection at the cost of premium.

Reading backtest results

Click any backtest in the list to open the detail view:

  • Equity curve — Portfolio value over time.
  • Summary metrics — Total return, Sharpe ratio, max drawdown, win rate, number of trades.
  • Trade list — Every entry/exit with date, price, and P&L.

Trade Page (E*TRADE Integration)

Place live or sandbox orders via the E*TRADE brokerage API.

Sandbox vs. live Set ETrade_SANDBOX=true (default) to use the E*TRADE sandbox. Switch to false only for real trading — all orders are real.

Setup

  1. Register an app at developer.etrade.com to get a Consumer Key and Secret.
  2. Add the credentials to Settings or your .env file.
  3. Complete the OAuth flow in the Trade page to get Access Tokens.

Available actions

  • View accounts and balances.
  • List open and filled orders.
  • Buy/sell equity (market or limit).
  • Buy options contracts (call or put, by expiry and strike).
  • Cancel open orders.
