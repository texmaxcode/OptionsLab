Key API Endpoints

Narrative guides (data pipeline, forecasting, risk, volatility, macro) are in Documentation.

All endpoints require a Bearer token from POST /auth/login except where documented otherwise. The interactive OpenAPI (Swagger) UI is at /docs on your API process (e.g. http://localhost:8000/docs while uvicorn runs locally). In production, API docs may be disabled — rely on this manual and docs/ in the repo.

Authentication

MethodPathDescription
POST/auth/registerCreate a new user account.
POST/auth/loginReturns a JWT token. Set-Cookie header included for browser use.
GET/auth/meReturns current user info. Use to verify token validity.

Forecast & Strategy

MethodPathDescription
POST/forecast/runRun ARIMA or GB forecast. Returns direction, forecast values, macro_enriched flag.
GET/forecast/runsList registered forecast runs. Query: symbol, model_type, limit.
POST/strategy-engine/evaluateEvaluate one strategy with forecast distribution. Optional: premium_paid, include_backtest.
POST/strategy-engine/discoverAuto-run forecast and rank all six strategies by expected value.

Volatility

MethodPathDescription
GET/volatility/{symbol}HV-10/20/30/60, IV Rank, IV Percentile, Expected Move (30d), IV and HV-20 time series.

Risk Tools

MethodPathDescription
POST/risk/position-sizeKelly, Half-Kelly, fixed risk, and max contracts from capital + win/loss inputs.
POST/risk/breakevenBreak-even prices for a strategy type given premium paid.

Research (LLM + RAG)

MethodPathDescription
POST/research/analyzeFull pipeline: forecast → strategy evaluation → RAG-augmented LLM explanation.
POST/research/explainLLM explanation for a provided forecast/strategy summary.
POST/research/rag/ingestAdd a custom document to the RAG knowledge base.
POST/research/rag/retrieveDebug: fetch top-k RAG chunks for a query.

Data

MethodPathDescription
GET/symbolsList all symbols stored in the DB.
GET/symbols/{symbol}/barsPaginated OHLCV bars. Query: from_date, to_date, page, page_size.
GET/symbols/{symbol}/contractsAll options contracts for a symbol.
POST/backtests/runRun a Backtrader backtest. Returns equity curve and trades.

Glossary

TermDefinition
ATMAt the money. The strike equals (or is closest to) the current underlying price.
ARIMAAutoRegressive Integrated Moving Average. A classical statistical model for time-series prediction.
Break-evenThe underlying price at expiry where a strategy's net P&L equals zero.
DTEDays to expiration. The number of calendar days remaining until an option expires.
Expected MoveThe market's implied ±1σ price range over a period, computed from IV.
Expected Value (EV)The probability-weighted average payoff of a strategy across all outcome scenarios.
FREDFederal Reserve Economic Data — the St. Louis Fed's free economic data repository.
GreeksDelta, Gamma, Theta, Vega, Rho — sensitivities of an option's price to market variables.
HVHistorical Volatility. Annualized std dev of log returns over a rolling window.
ITMIn the money. Exercising the option now would be profitable.
IVImplied Volatility. The vol value that makes a Black-Scholes price match the market price.
IVPIV Percentile. % of past trading days where IV was lower than today.
IVRIV Rank. Where today's IV sits in the past year's high/low range, 0–100.
JWTJSON Web Token. A self-contained, cryptographically signed auth token.
Kelly CriterionFormula for the optimal fraction of capital to risk per trade to maximize long-run growth.
OTMOut of the money. Exercising the option now would not be profitable.
P(profit)Probability of profit. The probability that a strategy expires with positive P&L.
PremiumThe price paid by the option buyer to the seller.
RAGRetrieval-Augmented Generation. Injecting relevant knowledge-base chunks into an LLM prompt.
Sharpe RatioReturn per unit of risk: (annualized return − risk-free rate) / annualized volatility.
Theta decayThe daily erosion of an option's time value as expiry approaches.
VaRValue at Risk. The maximum expected loss at a given confidence level over a period.
VegaSensitivity of an option's price to a 1% change in implied volatility.
